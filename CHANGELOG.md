# Changelog

All notable project changes are documented here.

## [0.1.0] - 2026-11-14

### Added
- Initial modular Kivy application foundation.
- Local SQLite persistence for tasks, notes, and focus sessions.
- Dashboard, tasks, notes, and focus screens.
- Shared theme tokens and reusable widgets.
- Initial persistence test suite.
- Architecture, roadmap, privacy, and contribution documentation.

### Notes
- This is an early foundation release, not a claim of feature completeness.
- Cloud synchronization, plugin support, and Android packaging are not included.
